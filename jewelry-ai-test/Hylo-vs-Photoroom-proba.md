# Проба Hylo против Photoroom на украшениях B'anis

Черновик Claude, 25.10.2026. Утверждает Баха.

## Зачем

Выбрать сервис для фото и видео украшений на модели. Главное требование
(из Start): **товар на фото не менять**. Украшение можно надеть, повернуть,
показать в движении, но его конструкция должна остаться прежней.

Чужие рейтинги для выбора не годятся:

- 4,6 из 5 и 78% удачных результатов — из исследования самого Hylo, не независимые.
- 29% и 38,2% у Photoroom — из одного теста переноса разных товаров на виртуальных
  моделей, не про бижутерию вообще.
- Цифры «94/100» и «28/30» для Nano Banana 2.1 — источник не найден, не использовать.

Поэтому решаем только по пробе на своих изделиях.

## Что проверяем

3 изделия, у каждого есть хорошее настоящее фото:

| № | Изделие | Что особенно легко испортить |
|---|---------|------------------------------|
| 1 | Браслет (лучше тот, с ромашками) | число бусин/подвесок, плетение, замок |
| 2 | Колье | длина, кулон, звенья цепи |
| 3 | Серьги (пара) | одинаковость пары, камни, швенза/застёжка |

Одинаковые исходники и одинаковое задание для обоих сервисов.

## Задания (одни и те же в обоих сервисах)

Для каждого изделия:

1. **Белый фон** — товар как на исходнике (для Amazon).
2. **На модели, крупно** — одно изделие, естественный свет.
3. **На модели, с лицом** — средний план, тот же товар.
4. **Видео 5–10 секунд** из фото — только если сервис умеет.

Текст задания (английский, для обоих):

> Put exactly this jewelry piece on the model. Keep the same number and shape of
> stones and beads, the same clasp, chain/weave, colors and real size.
> One piece only. Do not add, remove or redesign any part.

## Как оценивать каждый результат

Сверять с настоящим фото, не с прошлой генерацией. За каждый пункт: 1 — как в оригинале, 0 — изменено.

| Пункт | Что смотреть |
|-------|--------------|
| Камни/бусины | количество и форма те же |
| Замок | на месте и того же вида |
| Плетение/цепь | тот же рисунок звеньев |
| Цвет | металл и камни того же цвета |
| Размер на модели | реальный, не огромный и не крошечный |
| Одно изделие | нет лишних копий, браслет не стал колье |
| Красота | кадр можно ставить в рекламу (оценка Бахи) |

Итог кадра: **годен** только если все первые 6 пунктов = 1.

Видео оценивать отдельно: смотреть 3 кадра (начало, середина, конец) по тем же
пунктам. Хорошее фото не доказывает, что украшение сохранится в движении.

## Деньги

- Платную подписку Hylo по рейтингам **не покупать**. Сначала бесплатная проба.
- Hylo: по сторонним сайтам — стартовые бесплатные кредиты, Pro около $19/мес.
  Не подтверждено на сайте Hylo — проверить при входе.
- Photoroom: бесплатный план, по сторонним сайтам, без «виртуальной модели»
  и с водяным знаком; цены менялись в июле 2026. Проверить в приложении.
- Любая оплата — только после «да» Бахи.
